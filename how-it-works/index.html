FAQ

No. Ocotillo Yards is not a contractor. We visualize, then introduce an Arizona ROC crew if you want to build.

No. The crew we intro does.
Do you file with the HOA?
No. The homeowner or the hired crew does.
Is the concept free?
Yes — two views + an idea board.
Pools?
We do not install pools. We will not concept a pool as a construction bid.
